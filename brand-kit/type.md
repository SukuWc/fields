# SailZone typography

## In the logo (outlined / locked)

| Element | Face (approx.) | Weight | Notes |
|---------|----------------|--------|-------|
| Wordmark **SAILZONE** | **Saira** | ~650 | Condensed display; paths locked in SVG |
| Tagline *Race the rules.* | **Albert Sans** | ~480 | Secondary line under wordmark |

Google Fonts (for UI / marketing that match the lockup):

- [Saira](https://fonts.google.com/specimen/Saira)
- [Albert Sans](https://fonts.google.com/specimen/Albert+Sans)

Do **not** regenerate the logo from live fonts for production marks—use the SVG/PNG exports. Live fonts are for app UI, docs, and campaigns that sit beside the mark.

## Suggested UI type scale (app / web)

| Role | Face | Size | Weight |
|------|------|------|--------|
| H1 | Saira | 32–40 px | 650–700 |
| H2 | Saira | 24–28 px | 600–650 |
| H3 | Saira / Albert Sans | 18–20 px | 600 |
| Body | Albert Sans | 16 px | 400–480 |
| Caption / meta | Albert Sans | 12–13 px | 400 |
| Buttons | Albert Sans or Saira | 14–16 px | 600 |

Line-height: ~1.25 for headings, ~1.5 for body. Keep navy `#02285C` for primary text on light backgrounds; tagline teal `#177F8D` for accents only.
